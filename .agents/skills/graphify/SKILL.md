# Graphify Skill

Turn any codebase, docs, or folder into a persistent knowledge graph.

## Instructions

Follow the graphify instructions to run the full pipeline or query the graph.
If no path argument is given, use `.` (current directory).

### Key Commands:
- Build / Update: `graphify update .`
- Query graph: `graphify query "<question>"`
- Shortest path: `graphify path "<A>" "<B>"`
- Explain concept: `graphify explain "<concept>"`
